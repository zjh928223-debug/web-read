## 仍值得保留的最小实际使用检查

1. 从准备采用的正常主入口进入 SRS 和预习，能加载可操作内容；使用一组新建内容，并重新打开这组内容。
2. SRS 揭示、点击一次评分、数字键评另一卡，能够继续；快速重复操作不会多记一次。保存完成后刷新，确认学习记录实际保留，不能只看前端计数。
3. 预习揭示、下一词、关闭再打开、刷新，进度能恢复。相关底层保存／重启分支复用 C04 已有证据，不重跑整套 Host 验收。
