# 粘贴文章默认音频

用户要求无原始音频的粘贴文章默认带 Microsoft Aria Natural 美式英语语音。采用一次提交、后台按 AI 切分组合完整句子生成、合并成连续音轨后保存；不在播放时逐句请求。原始输入仍为 text-only，生成的素材为 pasted-article，旧纯文本素材继续兼容，不自动改写历史文章。

实现前固定验收：

1. 新粘贴文章默认生成 en-US-AriaNeural、-5% 语速音频，切分及中文释义沿用现有链路。原视频流程不变。
2. 按 AI chunk 范围取原文，完整覆盖所有词；短语尽量合并到句末，段落边界保留；后台生成并合成单一 WAV，前端播放不按句请求生成。
3. 用 Edge WordBoundary 及实际解码时长生成真实媒体时间，保持原词序与 chunk 索引，支持高亮、点击跳读及原有 owner 媒体读取。
4. 音频生成、解码或时间对齐失败时任务失败，不保存 ready 的无声结果；支持现有重试、可复用已完成的分句缓存；取消不继续提交结果。
5. 新素材保存音频、字幕、切分与原文，重新打开仍有音频；旧 text-only 素材仍可阅读，原有视频必须有音频的校验保留，IndexedDB schema 不变。
6. 定向后端与 JS 回归、生产构建、真实 Edge 生成及浏览器播放/跳读/重开分别验证。真实 AI、真实语音、受控 fixture 的结论分别记录；不更新全仓验收或旧项目推广状态。
