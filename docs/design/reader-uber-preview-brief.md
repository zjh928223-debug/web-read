## 一张页面，四个区域

| 区域 | 最少内容 | 需要看清的问题 |
| --- | --- | --- |
| 顶栏 | 素材按钮、示例文章名、设置按钮、浅/深色切换 | 标题与操作层级、整体灰阶和留白 |
| 控制区 | 上一句、播放/暂停、下一句；0.75×/1×/1.25×；跟随、AI 切分、中文、聚焦 | 胶囊比例、功能分组、普通/选中/禁用状态 |
| 阅读区 | 4–6 句自写英文及中文示例，一句当前句、一个已标记词 | 控制区与正文的比例、阅读舒适度、标记与主题是否协调 |
| 设置小弹窗 | 上一句/下一句快捷键输入，显示完整 ArrowLeft/ArrowRight；关闭、应用到预览 | 输入框、弹窗、按钮组合与焦点状态 |

页面角落简短标明“样式预览 · 示例数据”。初始展示浅色，允许切换深色。不加入素材管理全页、SRS 页面、完整设置、统计面板或长篇设计说明。

播放仅切换图标与文字，跳句切换当前句，倍速与模式按钮更新本地显示，中文控制示例译文显隐。AI 模式可以切换预先写好的分块示例，不调用 AI。快捷键只编辑输入样式，不注册全局快捷键。“应用到预览”仅更新内存状态，刷新恢复初始值。

## 外观与框架

- 采用参考的黑白灰、胶囊按钮、黑白反转选中态、8px 输入框圆角与12px弹窗圆角，少量轻阴影。
- 使用现有 Vue、Tailwind v4、shadcn-vue；通过现有组件、样稿局部配方、主题变量和 Tailwind 布局实现。不手写另一套控件皮肤，不增加液态玻璃、渐变或新的品牌色。
- 桌面初始采用 36px 常规控件、32px 紧凑选项、14px UI 文字、8px 控件间距、16px 组间距；窄屏触控目标至少44px。比例可小幅调整，但不能自由改换设计方向。
- 深色主操作和选中态用白底黑字，避免照抄参考中黑按钮消失在黑背景的问题。
- 正文用简洁的可读排版；语义标记只保留必要的少量颜色。不要为了展示风格加入营销页大标题、巨幅留白或配图。
- 现有 Button/Input 可以只读复用；需要调整配方时在样稿目录局部配置，不改产品共享文件。弹窗优先复用已有可用原语；不足时可使用浏览器原生 dialog 配合框架样式，不安装另一套组件库。
