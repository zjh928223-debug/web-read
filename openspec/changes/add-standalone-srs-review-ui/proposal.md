## Why

当前项目已经能把单词和语境保存到词库，并用 FSRS 计算复习时间，但缺少一个用户真正能打开和使用的复习页面。作为个人单机工具，本次只需补齐简单、可靠的每日复习闭环，不建设复杂的平台架构。

## What Changes

- 新增一个独立 SRS 页面，采用已选定的“平衡双栏”UI：左侧原文语境，右侧单词释义和五个评价按钮。
- 直接复用现有 `createVocabularyService()`、`getDueWords()` 和 `reviewWord()`，不重写排程算法。
- 五档评价固定为 `忘记 -> again`、`困难 -> hard`、`一般 -> good`、`容易 -> easy`、`掌握 -> easy + known`，并支持数字键 `1-5`。
- 单词面板优先显示加入 SRS 时保存的精简释义，不再显示单独的“提示”区。
- 增加上一张/下一张回顾控制和方向键导航；历史卡片只读，不重复评分。
- 增加“R 重读单词和原句”按钮及快捷键；空格键仅作为不显示 UI 的暂停/继续行为。
- 左侧原文中的英文单词可点击；有逐词时间戳时从对应原声位置播放，否则朗读该词之后的剩余句子。
- `R` 和空格由复习页全局捕获，不受当前焦点元素影响。
- 原文单词保持普通文本外观，仅在悬停或键盘聚焦时轻微放大。
- 重读快捷键可点击键帽后重新录入，按本地设置持久化并忽略字母大小写。
- 右栏将现有精简义标记为“句中释义”；只有存在独立词典字段时才额外显示“常用释义”，本变更暂不接入新的释义 API。
- 独立开发时使用用户现有词库的本地 JSON 副本和 in-memory repository，不写入真实词库。
- 原文音频只做简单恢复：能按 `source_id` 找到来源并匹配原句时显示，否则只显示文本语境。
- 页面完成并验证后，再增加一个 `今日复习` 入口接入现有阅读器。
- 移除笔记、重复播放入口、重复原句、底部提示、设置、更多信息和额外统计。
- 不修改 IndexedDB schema、数据库版本或现有 reader runtime。
