# Read-Web Vocabulary Learning

This context names the vocabulary-learning concepts that will become the reader's memory source for English study.

## Language

**Vocabulary Entry**:
A lexical item the learner wants to remember and review. It may be a single word, phrase, abbreviation, scientific name, geographic name, or other proper noun.
_Avoid_: Word, card, token

**Lemma**:
The canonical text for a Vocabulary Entry as it should be shown to the learner.
_Avoid_: Lookup key, normalized word

**Contextual Meaning**:
The AI explanation of a Vocabulary Entry in one specific sentence or occurrence.
_Avoid_: Dictionary definition, general meaning

**Review State**:
The current spaced-repetition memory state for a Vocabulary Entry.
_Avoid_: Progress, score
